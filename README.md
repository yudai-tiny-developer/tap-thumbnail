# Tap Thumbnail

A Chrome extension that adds a button to the YouTube player so you can quickly preview the current video's thumbnail.

## Features

- Adds a thumbnail button to the YouTube player controls
- Shows the current video's thumbnail in an overlay inside the player
- Supports the extension command for showing or hiding the thumbnail
- Works on `https://www.youtube.com/*`

## Usage

1. Open any video on YouTube.
2. Look for the thumbnail button in the player controls.
3. Click the button to show the thumbnail preview.
4. Click the thumbnail or move focus away to hide it.

### Keyboard shortcut

To assign a shortcut in Chrome:

1. Open `chrome://extensions/shortcuts`.
2. Find **YouTube Thumbnail Button**.
3. Set a shortcut for **Show/Hide Thumbnail**.
